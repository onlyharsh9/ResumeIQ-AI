# ResumeIQ AI — Frontend

Frontend interface of ResumeIQ AI, an AI-powered ATS Resume Checker platform.

This module provides the user interface where users can upload resumes, enter job descriptions, view ATS scores, and get AI-based resume improvement suggestions.

---

## Features

- Modern responsive user interface
- Resume upload interface
- ATS score visualization
- Resume analysis report display
- Career category prediction display
- AI-based improvement suggestions

---

## Tech Stack

- HTML
- CSS
- JavaScript

## Running Frontend

Open the `index.html` file in a browser.

For local development, you can use a live server extension in VS Code.

---

## Frontend Module

The frontend provides the visual layer of ResumeIQ AI and communicates with the backend API to display resume analysis results.
